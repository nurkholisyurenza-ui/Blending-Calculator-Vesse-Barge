Blending Calculator Guide Panduan Kalkulator Blending

1. Getting Started 1. Persiapan Awal

Upload your inventory data and vessel requirements to calculate optimal coal blends.

Unggah data inventaris dan kebutuhan tongkang/vessel untuk menghitung komposisi blending batubara yang optimal.

  • Upload Stocks: Unggah Stok: Click "Upload Stocks (CSV/Excel)" to import your available coal inventory. The file needs to contain columns like Stock ID, ROM, Available MT, CV, Ash, TS, Product. Klik "Upload Stocks (CSV/Excel)" untuk mengimpor inventaris batubara yang tersedia. File harus berisi kolom seperti Stock ID, ROM, Available MT, CV, Ash, TS, Product.
  • Upload / Add Vessels: Unggah / Tambah Tongkang: Click "Upload Excel/CSV" under Vessels or "+ Add" to specify ship requirements (Tonnage, Target CV, Max Ash, Max TS). Klik "Upload Excel/CSV" di bawah Vessels atau "+ Add" untuk menentukan kebutuhan kapal (Tonnage, Target CV, Max Ash, Max TS).
  • Select Product Brand: Pilih Brand Produk: Use the dropdown at the top left to filter the view for a specific product. Gunakan dropdown di kiri atas untuk memfilter tampilan pada produk tertentu.

2. Features & Actions 2. Fitur & Aksi

Global Actions (Top Bar) Aksi Global (Bilah Atas)
  • Clear Allocations: Clear Allocations: Resets all calculated values to zero. Mereset semua nilai alokasi perhitungan menjadi nol.
  • Auto-Solve All Vessels: Auto-Solve All Vessels: Automatically calculates the best blend using Linear Programming to meet all vessel targets efficiently. Secara otomatis menghitung komposisi terbaik menggunakan Linear Programming untuk memenuhi target semua tongkang dengan efisien.
  • Export Excel: Export Excel: Downloads the current blending plan as an Excel file. Mengunduh rencana blending saat ini sebagai file Excel.
  • Recalculate: Recalculate: Updates the result panels manually if you changed any inputs. Memperbarui panel hasil secara manual jika Anda mengubah input apa pun.
Global Rules Panel Panel Aturan Global
  • Auto-Diversity Max %: Auto-Diversity Max %: Sets a default maximum limit for any single stock to ensure the blend is well-mixed across multiple sources. Menetapkan batas maksimum default untuk satu stok agar campuran batubara tercampur rata dari berbagai sumber.
  • Add Rule: Tambahkan Aturan (Add Rule): Allows forcing an "Exact %" or overriding the "Max %" limit for specific stocks globally across the product. Memungkinkan pemaksaan "% Tepat" atau menimpa batas "Maks %" untuk stok tertentu secara global.

3. Ingredients Table Controls 3. Kontrol Tabel Stok

Fine-tune how stocks are allocated to specific vessels directly in the table.

Atur detail alokasi stok ke tongkang tertentu langsung dari tabel.

  • Manual Input: Input Manual: Type a value in the input box to manually assign MT to a vessel. Ketik nilai di kotak input untuk mengalokasikan MT ke tongkang secara manual.
  • Lock 🔒/🔓: Kunci 🔒/🔓: Click the padlock icon to freeze a manual allocation. Auto-Solve will not change locked values. Klik ikon gembok untuk mengunci alokasi manual. Auto-Solve tidak akan mengubah nilai yang dikunci.
  • Lim %: Batas (Lim) %: Set a strict maximum percentage limit for a specific stock for that particular vessel. Tetapkan batas persentase maksimum yang ketat untuk stok tertentu khusus untuk tongkang tersebut.
  • Apply to All: Apply to All: Copies the Lock and Max % settings from the first vessel to all other vessels for that specific stock row. Menyalin pengaturan Kunci dan Maks % dari tongkang pertama ke semua tongkang lain di baris stok tersebut.

4. Warnings & Results 4. Peringatan & Hasil

At the bottom of the page, the calculator displays outcomes:

Di bagian bawah halaman, kalkulator menampilkan hasil:

  • Results Panels: Panel Hasil: Shows the Achieved Tonnage, CV, Ash, and TS against the target limits. Indicates if the blend "Meets Spec" or is "Off Spec". Menampilkan Tonnage yang Dicapai, CV, Ash, dan TS dibandingkan batas target. Mengindikasikan apakah blending "Memenuhi Spek" atau "Luar Spek".
  • Shortage Warnings: Peringatan Kekurangan: If there isn't enough coal to fulfill all targets, a warning box will appear suggesting which high-CV stocks to replenish. Jika tidak cukup batubara untuk memenuhi semua target, kotak peringatan akan muncul menyarankan stok CV tinggi mana yang harus ditambah.

5. Blending Summary Report 5. Laporan Ringkasan Blending

A dedicated report panel appears automatically below the vessel results once data is loaded. It contains three sections:

Panel laporan khusus muncul otomatis di bawah hasil vessel setelah data dimuat. Berisi tiga bagian:

  • Overall Aggregate: Total Keseluruhan: Shows total target vs achieved tonnage across all vessels, plus overall weighted average CV, Ash, and TS. Menampilkan total target vs tonase tercapai semua tongkang, plus rata-rata tertimbang CV, Ash, dan TS secara keseluruhan.
  • Raw Material Usage (Grouped by Stock ID): Penggunaan Bahan Baku (Per Stock ID): Groups usage across all ROM sources with the same Stock ID. Shows total available, total used, remaining, and a utilization progress bar per material — even if the same material comes from different ROM locations. Mengelompokkan penggunaan semua sumber ROM dengan Stock ID yang sama. Menampilkan total tersedia, terpakai, sisa, dan progress bar utilisasi per material — meskipun material yang sama berasal dari lokasi ROM berbeda.
  • Stock Allocation per Vessel: Alokasi Stok per Tongkang: A detailed cross-table showing exactly how many MT of each stock (and its ROM) were assigned to each vessel, with percentage of the vessel's tonnage shown alongside. Tabel silang detail yang menunjukkan persis berapa MT setiap stok (dan ROM-nya) dialokasikan ke setiap tongkang, beserta persentase tonase tongkang tersebut.
